Stage 1–2

上传阶段四条硬约束：传源码文本、查完 Checksheet、不伪造门户样式

Bundle First

先拉规范，按需追加

默认 /bundle 一次返回 SKILL.md + style-guide + kit + diagrams；动效页追加 ?refs=motion，亦可用 POST /prepare 或 /prompts/<name>。

PUT Guard

只发 UTF-8 HTML 源码

最大 12 MiB，目标名须为 .html/.htm（禁止传 .src.html 后缀或本地文件路径），可附 ?note= 或 X-VE-Note 记录版本说明。

Wiki Drill

规范下钻与悬停摘要

页面必含 <meta name="description"> 供悬停卡片展示；节点写 data-ve-child="<child>"（省略 .html），严禁手写假 Portal CSS，由查看器运行时注入。

Stage 3–4

零空闲 Token 后台监听（watch.sh）与 Key 生命周期自动止停

Zero Idle

204 本地消化，零空闲 Token

禁止手写裸 once=1 curl 轮询或按页并发开多个监听；整目录只需一个 watch.sh 进程，重跑时 PID 锁自动优雅替换旧进程。

All Events

默认响应全量评论事件

省略 --events 时，新建评论、回复、重新打开与手动 Send 都会立即唤醒 Agent；仅需攒批发送时追加 --events comment.dispatch。

Key Lifetime

到期 / 撤销自动退出不续挂

服务端在 Key 过期、撤销或目录删除时主动断开长轮询与 SSE；脚本输出 key_expired / scope_gone 后 Agent 须静默停止，禁止重挂。

API Map

提示词第 4 节提供的完整协作端点速查

能力域 HTTP 方法与路径 关键参数 / 行为
读取官方规范 GET /bundle · POST /prepare · POST /prompts/<name> 支持 ?refs=motion,… 一次合拉多份参考
发布与读源码 PUT /files/<path>.html · GET /files/<path> 同路径覆盖自动递增 v2 / v3 版本
评论与线程闭环 GET /comments · POST /comments · POST /comments/<id>/resolve|reopen 回复已解决线程会自动重新打开；Resolve 可附 note
零 Token 监听 GET /watch.sh · GET /events（once / stream） 本地吞 204、默认全量 comment.*、支持 --after 与 Key 生命周期自动止停
目录与版本回溯 GET /tree · POST/PATCH/DELETE /folders · GET /versions · POST /restore 支持文件移动重命名与按 vN 恢复历史版本

拉完 bundle 后由 SKILL 接管视觉形态与出图规则，或返回 overview 查看全套体系。
