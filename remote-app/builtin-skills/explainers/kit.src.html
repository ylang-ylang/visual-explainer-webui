New in v0.16.0

三项 v0.16.0 核心增强：侧边目录、自动交叉引用、严格标签报错

长页桌面侧边目录（.ve-toc[data-layout="side"]）

包含 4 个及以上章节的页面，在 <main> 前放置 <nav class="ve-toc"> 即可获得滚动定位与进度计数；加上 data-layout="side"（本页即开启）会在宽屏自动切换为左侧固定栏，紧跟章节后的 <a class="sub" href="#h3-id"> 会缩进展示子标题。

自动图号、空链接回填与源码语法拦截

编译器按页面顺序为每个空的 <span class="fig-n"></span> 填入 Fig. N，并把对应图号写进指向 <figure id="…"> 的空链接中——例如 就是由空 <a href="#fig-compile"></a> 自动填出的。若源码出现未闭合标签、多余闭合标签或非法数据属性（如 line 42 <ve-bar>: value="-3" is negative），编译器直接报错且不写出损坏文件。

Kit Parts

内置语义零件直接复用，自定义 CSS 只覆盖差异

Kit 已为裸 <p>、<ul>/<ol>（65ch 栏宽）、<pre> 代码块与节内间距做好排版，页面只需写特有样式。SVG 节点与结构类遵循固定契约：

零件 标准标记 关键坑点 / 约束
SVG 节点 .ve-n <g class="ve-n [is-key]"><rect class="sh"/><text/><text class="sub"/></g> Kit 强制 text-anchor: middle，x 须填矩形中心；存储用 path.sh + ellipse.sh.lid
连线 .ve-e <path class="ve-e [is-hot|is-async]"/> + <text class="ve-el [l|r]"> 自带箭头；必须先画边再画节点；l 右对齐终点、r 左对齐起点
边界与文字标签 rect.ve-bnd + text.ve-bnd-t · <text class="ve-tag [key|risk]"> 任何缺少 fill 的 SVG <text> 会渲成纯黑并触发渲染错误
状态与变更标记 .is-new · .is-gone · <text class="ve-x">✕</text> · .chip ok|warn|risk .kpis > .kpi 支持 data-count 计数；.cases > .case[data-st] 用于小多图
联动与步进 data-ref="id" + <span class="ve-ref" tabindex="0"> · .ve-steps 悬停或聚焦正文术语时同步点亮图中对应节点与连线
