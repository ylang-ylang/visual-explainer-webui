Four Patterns

四种信息型动态组件与触发条件

动态机制 核心标记 / 结构 设计纪律
步进与场景播放 figure.ve-steps + .ve-player + data-s="N" 步数等于 ol.ve-cap > li 数量；每步必须有可见变化与一句主张；永不自动播放
状态机 / 事件回放 data-s="0 3 5" · .ve-tok · .ve-at · .ve-vals · rect.ve-slot 0 常驻底图；--dur 控时长（默认 900 ms），--d 做突发间隔；解说必须写清 because 触发条件；代码状态机优先交由 machines.md 自动遍历
Live 实时图 1–3 个 input[type=range] 或 button[aria-pressed] 单一纯函数 model(settings) 同步刷新图形、数字与结论句；默认停在真实值；JS 注入控件且打印隐藏
3D（three.js） importmap + 固定纵横比 .frame + CSS2DRenderer 仅在深度本身承载数据（空间布局/嵌入/高度量）时使用；框线图严禁 3D；限 DPR ≤ 2，可见才渲染，禁 bloom/雾/粒子

Allow vs Forbid

只动画合成层属性，彻底禁止装饰性循环与滚动劫持

允许 · 信息型

低开销、有因果、可停在终态

仅对 transform、opacity 与 stroke-dashoffset 做过渡，走 Kit 节拍 --fast（悬停）、--med（切态）、--slow（步进）；允许单层 data-flow 按真实比例派发流动点与 data-ref 联动高亮。

禁止 · 装饰型

绝不为了“炫”而动

禁止任何 autoplay 自动播、视差滚动（parallax）、滚动劫持（scroll-jacking）、无意义的呼吸灯/脉冲/弹跳循环，以及触发布局重排的 width/height/top 动画。

Reduced Motion & Capture

为什么 Checksheet 与 WebUI 缩略图采集必须关闭动效

页面加载时，Kit 会给文档挂上 .js-motion 让 <main> 下各区块轻抬淡入一次。若无头浏览器在加载瞬间直接截屏，首屏区块可能停在 opacity: 0 或半透明位移状态，描边与步进令牌也可能停在半途。

因此官方 Checksheet 体检与 WebUI 的 renderThumbnailBuffers() 都强制以 prefers-reduced-motion: reduce 和 animations: 'disabled' 采样，并注入 .js-motion main > * { opacity: 1; transform: none; transition: none; }。这样无论 Light/Dark 缩略图还是 1280px/390px 校验图，看到的永远是 100% 确定、完整清晰的终态画面。详见 style-guide 与 kit。
