Pick the Tool

常规框线交给 <ve-flow>，精确几何用手绘 SVG，Mermaid 仅按需

默认首选

<ve-flow> 网格自动排版

适合标准框线流、状态机与架构图：零手算坐标、自带 .frame 和回放令牌，但箭头标签须控制在约 12 字符以内，且不可硬塞不支持的图形。

精确表达

手绘 Inline SVG

当需要流动点 data-flow、时序生命线、表结构 Schema、同坐标 Before/After 切换、.ve-dim 尺寸线或定制分组结构时，直接手绘 SVG。

仅显式要求

Mermaid pre.mermaid

仅在用户要求或直接提供 Mermaid 源码时使用；编译为静态 SVG 并自动配色，不支持步进或回放，且严禁附带脚本或主题配置。

Layout Rules

双视口（1280px / 390px）防截断、防重叠的七条几何清单

检查项 硬指标 / 规范 常见翻车与解法
节点规模上限 单图超过 ~12 节点立即拆分 保留 5–8 节点总览图，把细部下沉到卡片、第二张图或 data-ve-child 子页
双视口字号底线 SVG 标注 ≥ 14 单位；390px 窄屏最小字 ≥ 12px 宽 viewBox 配合小字号会被压糊；控制总宽在 760–860 并保持字号 ≥ 14u
连线与文字防压 正交路径 M x y H x V y；标签在边上方 9u 必须先写 .ve-e 再写 .ve-n；两线过近会产生干扰第三形状，加大间距或合并
手动折行与配色 SVG 文本不自动换行；单行约 ≤ 18 字符 用 <tspan x="…" dy="1.2em"> 折行；所有文字用 Kit 类上色避免变黑报错
尺寸线 .ve-dim 45° 端线，数字居中在线上 6u，每图仅一条 .is-key 多段连续跨度排在同一导轨，总跨度排在外侧导轨；数值绝不压在线上
流动点与对比 data-flow + data-every 比例反映真实流量 全页只保留一层流动点，路径经节点中心穿过；Before/After 用同坐标 --ok 增 / --risk 虚线删
联动与小多图 每图用 data-ref 绑定 2–4 个关键术语 小多图 .ve-mini 共享同一坐标系且文字 ≥ 14u，只把变化部件标 .is-st

若图形需要分步展开、回放事件或实时调参，继续查看 motion；基础组件契约见 kit。
