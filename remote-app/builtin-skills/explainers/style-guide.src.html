信号色 中性底与文字
设计维度 强制标准 细节要求
色彩语义与对比 一主色占屏 ≤ 10%；状态色专职专用 ok / warn / risk / info 仅表状态；弱化文字用 --text-dim 禁调 opacity；语义框用 --border-bright（3:1），装饰线用 --border
线宽与视觉层级 ground < structure < data < signal 结构线 1px，数据/轮廓 1.5–1.75px，唯一热路径 2.5–3px；每图只设一个 .is-key 光环与一条 .is-hot 路径
排版与数值格式 正文宽 65ch，边注 40–50ch，左对齐不两端对齐 表/KPI 用 tabular-nums 且右对齐；标清单位与基准；规范用弯引号、–、—、−、× 与 &nbsp;
网格与留白节律 12 栏对齐同一左边线；标题上距为下距 2–3× 宽图→指标条→小多图→短文交替，禁连续三个同构块；先用留白、再细线、最后才加框；间距只用 --s-1…--s-8，圆角仅 --r-1 / --r-2
主题微调（Motif） 最多 2–3 处克制行业辨识度 主题主色校准至双主题 4.5:1（若撞红/绿状态色则保留原语域色）；背景纹 ≤ 15% 对比度；删掉不影响可读性的全砍

Anti-Slop

封杀 AI 塑料感：克制装饰、拒绝模板堆叠

禁卡片套娃

无“卡中卡”与彩色侧边条

Callout 直接用 --surface、--r-2 与状态芯片作标题，严禁圆角卡片配彩色左竖条；阴影 --lift 仅用于浮起节点与弹层。

禁无信息墨水

砍掉图框、厚网格与 3D 柱

数据标签直接贴在图形旁，少于 5 组不画图例；柱状图必须从零起算且按值排序；折线图宽高比约 2:1–3:1；标签跨线加 --bg 描边护底。
